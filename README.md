# pdviewer

A fast, minimal, open-source PDF viewer for macOS. Swift, SwiftUI, PDFKit. No dependencies.

**Status:** planning. No code yet. See [docs/PLAN.md](docs/PLAN.md).

## Why

Preview is heavy and slow to open large files. Browser tabs lose your place. pdviewer
aims to do one thing: open a PDF instantly, let you read and search it, and remember
where you were.
